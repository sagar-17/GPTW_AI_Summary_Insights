What consultants get (Snowsight → Streamlit app)

  • Overview: sentiment by dimension, top strengths & gaps
  • Themes: prevalence %, drill-down to evidence quotes
  • Demographics: theme heatmap by tenure, age, gender, level
  • Risk radar: priority quadrant, hotspots, AI risk flags
  • Leadership brief & Ask the data: AI answers based only on the filtered data
  • Comments: searchable record behind every number

Going to production (2.5 lakh+ comments / year)

  • Process only new comments: stream + task, MERGE
  • Record prompt / model / glossary version per row
  • Pre-filter blank & irrelevant text (AI_FILTER)
  • Peak sizing Oct–Feb · budgets & resource monitors
  • Reference set vs analyst coding · human overrides
  • Hide groups under ~5 respondents (confidentiality)
  • AI_REDACT names & personal details · masking policies
  • Row access per client company
  • Cortex Analyst + Search + Agent for chat at scale
  • Add industry, employee size, survey year · dev/test/prod + Git CI/CD
